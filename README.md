💧 Water Care – Community Service Project (CSP)

📌 About the Project

Water Care is a web-based Community Service Project designed to spread awareness about water conservation, provide information about water availability, and help community members report water-related problems.

The website provides a simple and user-friendly interface for viewing water information, checking facilities, submitting complaints, tracking reports, and learning about water conservation.

🎯 Objectives

- Promote water conservation and responsible water usage.
- Provide information about water availability in the community.
- Help users report water-related issues.
- Allow users to track submitted reports.
- Collect community feedback through surveys.
- Spread awareness about clean and safe drinking water.

✨ Features

🏠 1. Home Dashboard

- Provides an overview of the Water Care website.
- Offers easy navigation to the main sections.
- Displays key water-related information.

🗺️ 2. Water Availability Map

- Provides a map-based interface for viewing water availability locations.
- Helps users identify water-related locations in the community.

💧 3. Water Status

- Displays water status information.
- Helps users understand the availability of water in different locations.

🏢 4. Water Facilities

- Provides information about available water facilities.
- Helps community members locate relevant water resources.

📝 5. Report an Issue

- Allows users to submit reports about water-related problems.
- Supports community participation in identifying local water issues.

🔎 6. Track Report

- Provides an interface to check the status of submitted reports.
- Helps users follow up on reported issues.

📊 7. CSP Survey

- Provides a survey section to collect community feedback.
- Helps understand local water-related problems and community needs.

🏫 8. About College

- Displays information about the college associated with the Community Service Project.
- Can include college details and campus images.

🌱 9. Water Awareness

- Provides information about water conservation and responsible water usage.
- Encourages people to protect water resources and avoid wastage.

🚀 Getting Started

Prerequisites

- A web browser such as Chrome or Firefox
- Visual Studio Code (recommended)
- Git, if you want to clone the repository

Installation

1. Clone the repository:
   
   git clone YOUR_GITHUB_REPOSITORY_URL

2. Open the project folder in Visual Studio Code.

3. Open `index.html` in a browser or use the Live Server extension in VS Code.
4. The CSP presentation page appears first. Select **Enter Project** to open the existing Water Care sign-in screen; the existing dashboard and features remain in that portal. Use the browser Back button to return to the presentation page.
5. Choose **Create an account** to register a demo account in this browser, then choose a workspace to open the portal.

🔄 Project Workflow

1. The user opens the Water Care website.
2. The user explores water availability, water status, and facilities.
3. The user reports a water-related problem if needed.
4. The user uses the tracking section to check the report status.
5. The user participates in the CSP survey.
6. The user learns about water conservation through the awareness section.
